# Shared video execution rules

Load once after entering BabblelabReel. Resolve all bundle paths from
`BABBLELABREEL_ROOT`, not the target project. Use the user's language and
outcome; do not ask users to select implementation engines.

For help-only requests, explain without creating files or running providers.
For execution, use the chosen branch's local prerequisite checks. Missing
dependencies are explicit blockers requiring scoped installation consent.
Use actual host tools; a provider failure does not authorize switching
accounts, reading cookies, incurring fees or uploading private media.

Use `skills/_shared/artifact-routing.md` before writing user files. Preserve
originals and editable sources, signed-link privacy, attribution, truthful
product evidence, narration coverage and the requested output constraints.
Follow direction/audition gates unless the user explicitly delegated them.
Ask one focused question for a consequential unknown; do independent work.

For child audio/image tasks, read the bundled child's SKILL.md directly.
Scripts resolve their own bundle root and use the bundled canonical path
resolver. Source assets, generated media and runtime dependencies are distinct:
their presence or readiness is not evidence a requested video was rendered.
Inspect real output, report factual paths and quality limits, and retain
provider/license provenance. No automatic publication or setup side effects.
